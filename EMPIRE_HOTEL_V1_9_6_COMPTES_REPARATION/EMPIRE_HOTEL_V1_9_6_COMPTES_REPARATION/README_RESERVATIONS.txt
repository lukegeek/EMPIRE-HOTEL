EMPIRE HOTEL V1.9 - FICHES DE RESERVATION

Nouveauté : onglet « Réservations » disponible pour chaque hôtel.
La fiche contient : nom, prénom, nombre de personnes, nombre de nuitées,
date d'arrivée, date de départ, fourchettes de taxe de séjour, prix de chambre
et frais de ménage, acceptation/refus du contrat.

Si le contrat est accepté, le serveur attribue automatiquement un numéro de
chambre disponible sur toute la période du séjour. Les chevauchements de
réservations sont vérifiés côté serveur. Si le contrat est refusé, aucune
chambre n'est attribuée.

Les fiches sont enregistrées dans le compte du joueur et conservées dans
EMPIRE_HOTEL_SAUVEGARDES/players.json lors des redémarrages et mises à jour,
à condition de conserver ce dossier.

Installation : npm install puis npm start ; ouvrir http://localhost:4177.
IMPORTANT : décompresser l'archive dans un dossier neuf. Ne pas supprimer
EMPIRE_HOTEL_SAUVEGARDES. Arrêter l'ancien serveur avant de lancer cette version.
