EMPIRE HOTEL — RENDER — 3 FICHIERS
Remplacer les fichiers dans le dossier EMPIRE_HOTEL du dépôt GitHub.
Render : Language Node ; Branch main ; Root Directory EMPIRE_HOTEL ; Build Command npm install ; Start Command npm start.
Le serveur utilise PORT et écoute sur 0.0.0.0 en hébergement. RENDER_EXTERNAL_URL est autorisée pour les requêtes du navigateur. Pour un domaine personnalisé, définir PUBLIC_URL avec son URL HTTPS.
En local : npm install puis npm start ; http://localhost:4177.
IMPORTANT : les comptes sont stockés dans un fichier JSON. Sans disque persistant, les sauvegardes Render peuvent être perdues à chaque redéploiement ou redémarrage. Pour un disque persistant monté, définir EMPIRE_HOTEL_DATA_DIR vers un dossier de ce disque. Les sessions sont en mémoire et nécessitent une reconnexion après redémarrage.
Ne pas envoyer node_modules ni les sauvegardes sur GitHub.
